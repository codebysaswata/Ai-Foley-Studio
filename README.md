# AI Foley Studio

Desktop landing page for AI Foley Studio, built with Kotlin and Compose Desktop.

## Run it

Open this folder in IntelliJ IDEA or Android Studio, allow Gradle to sync, and run the `MainKt` configuration.

If Gradle is installed locally, run:

```powershell
gradle run
```

## Included

- Custom desktop title bar with window controls
- Responsive landing-page layout based on the supplied design
- Interactive navigation and call-to-action dialog
- Code-drawn waveform, headphones, clapperboard, and feature icons (no external image required)
- Native MSI/EXE packaging configuration in `build.gradle.kts`
